Google Sheet Database Schema (5 Tabs)

  • Containers: Container Number, Carrier, Material, Origin, Destination, ETA, Baseline ETA, Status, Vessel, Voyage, Last Update, Source
  • Tracking Events: Container Number, Event Type, Event Location, Event Date/Time, Event Description
  • Suppliers: Supplier Name, Country, Origin, Material, Price, Capacity, Lead Time, Quality Certifications, Status
  • Cost Analysis: Material, Quantity, Domestic Landed, Import Landed, Net Variance, Batch Savings, Optimal Choice, Timestamp
  • API Logs: Request Time, Container Number, Provider, Response Status, Last API Update, Error Details
Deployment & GitHub Pages Checklist Hosting Guide
  1. Rename this downloaded file to index.html.
  2. Create a public GitHub repository (e.g., cablesource) and upload index.html.
  3. Go to Settings → Pages → Build and deployment, select Deploy from a branch (main / root), and click Save.
  4. Open your live GitHub Pages URL (https://<username>.github.io/cablesource/).
  5. Verify the top-right status badge turns green (Google Sheets Live Synced) and click Open Google Sheet ↗ to inspect live records during your presentation.
